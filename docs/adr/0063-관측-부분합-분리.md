# 0063. 관측 환산액 부분합은 별도 응답 필드로 반환한다

## Status

Accepted — 부분 대체: [ADR 0071](0071-서버-환산은-단일-카탈로그를-쓰고-가격판-기록을-제거한다.md)이 다른 가격판의 부분합을 막는 조건을 제거한다. 나머지 규칙은 유지한다.

기존 상태 근거: Accepted — 허브 ADR 0011의 backend 구현.

## Context

UsageTotals는 이미 가격이 있는 행의 합과 미가격 행수를 조회한다. 전체값의 엄격한 null 규칙은 평균·비중·알림에서도 사용하므로 바꾸지 않는다.

## Decision

`knownEquivalentCost`는 사용 행 중 가격이 있는 행이 있을 때만 기존 cost 합을 반환하고 가격판 혼재에서는 null이다. OverviewValues가 기존 기간·가격 미확정 사유를 붙인다. 개요 summary/trend와 팀 metrics/trend에 부분합 및 priced/unpriced 행수를 추가한다. 기존 전체값·비교·세션 규칙은 유지한다. 기존 캐시도 새 앱에서 응답을 다시 조립하므로 snapshot 저장소 변경은 필요 없다.

## Alternatives Considered

전체 equivalentCost의 조건을 완화하면 기존 소비자에게 부분합을 전체값으로 전달하므로 제외한다. FE에서 모델 금액을 합하면 일별 원천과 불일치하므로 제외한다.

## Consequences/Tradeoffs

### Positive

추가 ClickHouse 쿼리 없이 같은 snapshot의 정확한 부분합을 제공한다.

### Negative

선택 기간의 전체 금액과 부분합을 별도 필드로 유지해야 한다.
