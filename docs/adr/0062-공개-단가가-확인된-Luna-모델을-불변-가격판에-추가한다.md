# 0062. 공개 단가가 확인된 Luna 모델을 불변 가격판에 추가한다.

## Status

Accepted — ADR 0061의 기본 가격판 v3와 정규화 판 6을 v4·7로 개정한다. 이전 가격판과 원천 보존·재처리 경계는 유효하다.

정규화 판은 [ADR 0064](0064-확인된-Desktop-완료-분기만-사용량-프로파일에-추가한다.md)에서 8로 개정한다. 가격판 v4와 이 문서의 단가는 그대로 유지한다.

## Context

허브 ADR 0010은 실제 로컬 원본의 Luna 모델을 공개 단가로 평가하고 가격이 확인되지 않은 자동 검토 모델을 null로 유지한다. v3는 GPT-6 Astra만 지원하므로 공개 가격이 있어도 두 Luna 모델을 계산하지 못한다.

## Decision

1. `CurrentPublicPrices.PROFILE_V3`·`VERSION_V3`·`AS_OF_V3`로 기존 v3를 보존한다. 새 기본 `public-standard-global-reference-2026-10-16-v4`의 기준 시각은 `2026-10-16T08:03:52Z`, `RowVersioning.NORMALIZER_REV`는 7이다.
2. v4는 v3의 일곱 모델 단가를 유지하고 `gpt-5.6-luna`·`gpt-6-luna`를 추가한다. 정확 ID와 `codex-responses-inclusive-v1`만 연결하며 prefix·유사 이름을 매핑하지 않는다. 두 모델의 input/read/write/output USD/M은 각각 `0.20/0.02/0.25/1.20`, `0.10/0.01/0.125/0.50`다.
3. 두 모델 모두 단일 요청 전체 입력이 272,000을 초과할 때 입력/cache×2, 출력×1.5다. 272,000은 기본 단가다. 비중복 uncached/read/create/output을 곱하고 reasoning/tool을 다시 더하지 않는다. 누락 성분과 미검증 의미는 null로 유지한다.
4. `codex-auto-review`는 카탈로그에 추가하지 않는다. 로컬 Codex commit `cec8c6fb876e90b20250ec740e970e3f33b7396f`의 `models-manager/models.json`은 별도 숨김 모델로 설명한다. `model-provider/src/provider.rs`의 `approval_review_preferred_model`은 일반 인증에서 `codex-auto-review`, API-key 인증에서 `gpt-5.6-luna`를 고른다. 이 분기는 backend 동일성이나 가격의 근거가 아니다. 공식 모델/가격 문서에서도 정확 ID의 단가를 확인하지 못했다.
5. 실제 원본 수집일·토큰·모델·보고 비용을 유지한다. 이번 작업은 v4로 별도 tenant에 처음 적재하며 기존 테스트 조직의 v3 관측과 증거를 수정하지 않는다. 생산자 의미 지원 확대는 가격 모델 추가와 별도로 검증한다.

## Alternatives Considered

### v3를 직접 수정한다

동일 pricing_version의 재현성을 잃으므로 새 판을 만든다.

### 자동 검토 모델에 Luna 단가를 대입한다

같은 역할은 동일 모델이나 요율의 증거가 아니므로 채택하지 않는다.

## Consequences/Tradeoffs

### Positive

- 공식 단가가 있는 실제 원본 모델의 환산액을 계산한다.
- v1/v2/v3 재현성과 미지원 모델의 정직한 상태를 유지한다.

### Negative

- 자동 검토 모델의 금액은 공개 근거 확보 전까지 계산할 수 없다.
- 현재 참조 평가이며 과거 청구를 복원하지 않는다.

## Acceptance Criteria

- 두 모델의 독립 Decimal 산식, 271999/272000/272001 경계, 누락·미검증·비슷한 ID·자동 검토 null을 검증한다.
- v3의 일곱 모델·기준 시각·기존 금액은 그대로이고 Luna는 v3에서 null이다.
- 현재 프로파일 기본 배선과 정규화 판 7을 검증한다.
