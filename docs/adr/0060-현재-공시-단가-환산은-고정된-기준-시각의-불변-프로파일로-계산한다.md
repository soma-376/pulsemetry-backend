# 0060. 현재 공시 단가 환산은 고정된 기준 시각의 불변 프로파일로 계산한다.

## Status

Accepted — 부분 대체: [ADR 0061](0061-캐시-생성-5분-참조-단가와-검증된-토큰-의미로-기존-관측을-재평가한다.md)이 v3의 캐시 생성 5분 평가와 기존 관측 재처리를 정한다. v1/v2의 불변 정책, 원천·관측 식별·보고 비용의 분리는 유효하다.

## Context

허브 ADR 0008은 현재 공시 Standard/global 토큰 단가를 환산 기준으로 정한다. 기존 `PricingStage`는
`source_time` 유효 요금만 고르므로 현재 공시 표를 과거에 유효했다고 표기하지 않고 별도 기준이 필요하다.

## Decision

- `PricingProfile`의 기본은 기존 `EVENT_TIME`이고 `CURRENT_REFERENCE`만 고정된 `referenceAsOf`로 요금을 고른다.
  현재 기준 프로파일에는 출처 URL·평가 기준·통화가 있어야 한다. `pricing_version`은 이 불변 설정의 ID다.
- 검토한 공식 단가는 adapter의 불변 카탈로그에 둔다. ingest 조립이 이름으로 선택하며 `none`도 명시적으로 지원한다.
  알 수 없는 이름은 기동에서 거절한다. 요청 중 외부 가격 조회나 기본 모델 매칭은 없다.
- **v1/v2 정책 — v3는 ADR 0061로 대체됨.** 첫 카탈로그는 검증된 `claude-code-exclusive-v1`과 네 정확한 Claude 모델의 uncached input/output/cache read다.
  cache creation은 명시 0에서만 가격을 계산한다. 양수 TTL 불명과 미보고는 null이다. Codex 미검증 의미는 그대로다.
- **초기 검증 단계 — 재처리 보류는 ADR 0061로 대체됨.** 정규화 판을 4로 올리고 원천 221행을 보존해 새 파생 신호로 수집 경로를 검증했다. 승인된 기존 관측의 새 재평가는 ADR 0061을 따른다.
- API와 화면은 기존 사용 환산액 필드를 사용한다. 벤더 보고 금액·계약액·청구액을 이 필드에 대입하지 않는다.

### 카탈로그 후속 판

같은 결정 아래 두 번째 카탈로그는 공식 문서로 확인한 `claude-sonnet-5-5`와 `claude-opus-4-8`을 더한다.
v1의 ID·가격·기준 시각은 선택 가능한 불변 값으로 남긴다. v2의 조회 기준은 `2026-10-15T23:29:51Z`,
정규화 판은 5다. **v2 검증 단계 — 재처리 보류는 ADR 0061로 대체됨.** 이 단계에서 기존 221행과 v1로 검증한 새 45행은 재처리하지 않았다. 새 여섯 모델 검증 입력은
두 모델 출시일 이후인 2026-10-01에 둔다. 이는 모델 범위의 확장이며 TTL·의미 검증·현재 기준 평가 정책은 그대로다.

## Alternatives Considered

### `validFrom=0`으로 현재 가격을 모든 과거에 적용한다

과거 가격 유효성 주장을 만들기 때문에 배제한다. 기존 사건 시각 모드도 유지해야 한다.

### API에서 총 토큰에 단일 요금을 곱한다

캐시·출력의 다른 단가를 잃고 적재 hash의 결정성에서 벗어나므로 배제한다.

## Consequences/Tradeoffs

### Positive

- 기존 모드를 보존하면서 현재 기준 평가의 시각과 의미를 명시한다.
- 순수 가격 단계의 단위 검증과 실제 ingest/API의 독립 산술 대조가 가능하다.

### Negative

- 현재 첫 프로파일의 범위 밖 성분·모델은 계속 null이다. 전체 비용 표시를 위해 값을 추정해서 채우지 않는다.
- 현재 기준 카탈로그 업데이트는 코드 검토·새 버전·정규화 판 갱신이 필요하다.
